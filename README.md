# VoxelCraft 方块世界

跨网联机体素沙盒游戏。不同网络也能一起建造与冒险。

## 🌐 官网

**[huhubasic.github.io/voxelcraft](https://huhubasic.github.io/voxelcraft/)** — 游戏介绍、联机教程、OP 命令参考、更新日志

- [VoxelCraft.apk](https://github.com/HuHuBasic/voxelcraft/releases/download/v1.2.0/VoxelCraft.apk) — 游戏客户端 v1.6.0（4.7MB）
- [VoxelCraftServer.apk](https://github.com/HuHuBasic/voxelcraft/releases/download/v1.2.0/VoxelCraftServer.apk) — 独立服务器 v1.2.0（97KB）

## ✨ 特性

- 🌐 **跨网联机** — 不同 WiFi/4G/5G 网络也能一起玩
- 🖥️ **独立服务器** — VoxelCraftServer.apk 可独立开房
- 👑 **完整 OP 权限** — 18 个管理命令（kick/ban/mute/teleport/time/gamemode 等）
- 🔄 **全版本兼容** — 当前/老/未来客户端均可联机
- 🧪 **酿造与变异** — 酿造台、变异药水、矿物系统
